# Публикация для сотрудников (BuildIn)

## Что выкладывать

Один файл:

```text
agent\release\monitor-agent\MonitorAgentSetup.exe
```

или архив:

```text
agent\release\monitor-agent.zip
```

Сборка у администратора:

```powershell
cd C:\Users\Гришаня\monitor-telegram-bot\agent
.\build.ps1
```

---

## Текст карточки BuildIn

**Название:** Агент мониторинга мониторов

**Кратко:**  
Ставится на кассовый / мини-ПК. Сообщает на сервер, включён ли монитор.

**Установка:**

1. Получите у администратора **токен** и **имя точки**.
2. Скачайте `MonitorAgentSetup.exe`.
3. Правой кнопкой → **Запуск от имени администратора**.
4. Введите токен и имя → **Установить**.
5. Сообщите администратору — он проверит, что точка онлайн.

Python не нужен. Автозапуск создаётся сам.

**Сервер:** `http://94.159.18.22:8787`

## Администратор

1. `/add_point Имя` в Telegram → токен  
2. Выдать Setup.exe + токен + имя  
3. Проверить на `http://94.159.18.22:8787/`
