# Агент мониторинга мониторов

## Установка (для сотрудников)

1. Скачайте **`MonitorAgentSetup.exe`**
2. Правой кнопкой → **Запуск от имени администратора**
3. В окне укажите:
   - **Токен точки** (от администратора)
   - **Имя точки** (например `Касса-1`)
   - папку установки (по умолчанию `C:\monitor-agent`)
4. Нажмите **«Установить»**

Установщик сам:
- скопирует программу в папку;
- сохранит настройки;
- создаст **автозапуск при входе в Windows**;
- запустит агент.

Python и ручная распаковка не нужны.

---

## Что делает агент

Следит, включён ли монитор, и отправляет статус на сервер  
`http://94.159.18.22:8787`

---

## После установки

| | |
|--|--|
| Папка | `C:\monitor-agent` (или выбранная) |
| Лог | `agent.log` в папке агента |
| Автозапуск | Планировщик заданий → задача `MonitorAgent` |

**Удаление:** снова запустите `MonitorAgentSetup.exe` → кнопка **«Удалить с ПК»**.

---

## Администратору

1. Создать точку: Telegram `/add_point Имя`
2. Выдать сотруднику: `MonitorAgentSetup.exe` + токен + имя
3. Проверить точку на сайте мониторинга
